## PDF RAG Chatbot Frontend

Minimal ChatGPT-style React frontend for the existing PDF RAG backend.

### Tech stack

- React + Vite
- Axios for API calls
- Basic CSS (no UI framework)

### Running the frontend

1. Install dependencies:

```bash
cd /Users/gagansmac/Documents/learn/rag/chatbot-with-RAG
npm install
```

2. Start the backend API (from the `api` directory) if not already running.

3. Start the frontend dev server:

```bash
npm run dev
```

Then open the printed `http://localhost:5173` URL in your browser.
